DrakorID TV — Sequence Flows

Browse → Detail → Play · Auth Flow · Search Flow

Browse Flow

  • • HomeScreen → HomeVM → MovieRepo → ApiService
  • • Reactive: StateFlow drives UI recomposition
  • • D-pad navigation between grid items
  • • Coil loads poster images asynchronously
  • • Infinite scroll via page parameter

Play Flow

  • • DetailScreen → select episode
  • • GET /v2/generate-link/play-max?episodeId=X
  • • Response: {status, url, message}
  • • Pass URL to ExoPlayer (HLS/m3u8)
  • • Fullscreen TV playback with remote control

Auth Flow

  • • POST /v2/users/login → JWT token
  • • Token stored in DataStore (persistent)
  • • AuthInterceptor attaches Bearer token
  • • Login screen: email + password fields
  • • Google Sign-In: OAuth WebView on TV
